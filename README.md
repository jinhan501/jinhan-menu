# 金漢柿餅教育農園｜網站重製原型

這是一套可直接部署至 GitHub Pages 的靜態網站，不需安裝套件或執行建置指令。

## 網站內容

- `index.html`：首頁
- `about.html`：品牌故事
- `experiences.html`：導覽與柿染體驗
- `products.html`：產品比較、保存與訂購
- `knowledge.html`：柿子品種與知識
- `visit.html`：地址、營業時間與預約方式
- `404.html`：找不到頁面
- `assets/`：共用樣式、互動程式與壓縮後圖片

## 上線方式

1. 將本資料夾內所有檔案放入 GitHub repository 的發佈分支。
2. 在 repository 的 **Settings → Pages** 選擇該分支與根目錄。
3. 儲存後等待 GitHub Pages 產生網址。

如果要替換照片，保留原檔名與副檔名即可；若更換尺寸比例，請再檢查手機與桌面版裁切位置。

## 上線前建議確認

- 園區地址、電話與營業時間
- 體驗方案、費用、人數與開放日期
- 商品、保存期限與線上賣場網址
- Facebook 與預約表單網址

本原型依舊站現有內容整理，沒有修改原網站資料夾。

到訪頁使用 Google 地圖嵌入，不需要另外申請 API 金鑰；訪客瀏覽時需要可連線至 Google 地圖服務。
